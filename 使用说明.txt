易方 / MODUS 协作工作台 · 基础版

启动
双击 start.cmd，浏览器会打开 http://127.0.0.1:8765。
首次使用时设置两人的姓名、账号和密码，之后分别登录。
可以选择导入示例项目与事项。示例内容会明确标注，可取消勾选后从空白工作台开始。
运行需要 Python 3.10 或以上，应用本身只使用 Python 标准库。

七个页面
工作首页：左侧自己的待办，右侧同伴待办，下方为包含今天的五天时间轴。
项目详情：完整周期和阶段时间表、动态文件区域、文件上传和下载。
沟通意向：线索发现、沟通、最终方案报价已提交三个阶段，支持原帖、图片、历次沟通和自动跟进。
工作归档：分别显示两人的完成记录，可以按日期查看。
成功项目：开发全部完成且尾款实际到账的项目。
失败项目：第三阶段未达成合作的意向，保留失败原因及完整资料。
项目外待办事项：日常提醒的小方块，悬停预览、点击详情，与首页和完成归档同步。

基础操作
通过首页“新增事项”设置负责人、起止日期、具体时刻及所属项目或意向。
勾选自己负责的事项即记录完成，并同步到归档。可在详情中恢复为待办。
新建项目后，可以添加阶段、文件区域及项目事项。点击项目周期长条展开详情。
项目固定八阶段：项目准备、资料接收、需求澄清、方案与开工对齐、开发实现、整体验证、交付验收、复盘改进。
在阶段卡片点“查看与更新阶段”，填写工作内容，选择实际状态。已完成或不适用需说明依据，已完成可填写真实完成时间。
待办可以选关联阶段，但勾选、撤回、新增、回收待办都不影响阶段或项目状态。阶段状态也不改变待办状态。
确认实际开发全部完成时，在项目详情点“确认开发完成”，填说明及实际时间；需要返工时点“恢复开发”。项目开发完成且尾款到账后进入成功项目。
工作归档保留完成的待办，已确认开发完成的项目在归档项目中继续查看，未完成待办仍会保留。
每个文件区域右上方的上传按钮用于上传，文件名用于下载。
文件上限为每份 20 MB。基础版采用浏览器直接上传。
空文件区域可以移除，已有文件的区域保留其文件关系。

日常维护
点击事项打开详情后，可编辑名称、说明、日期和负责人，也可移入回收站。
日期尚未确定时，勾选“日期待定”，以后编辑时再补排。
项目下方提供项目编辑，展开后可编辑阶段、文件区域及排列顺序。
文件可重命名、调整负责人，并移动到其他项目的资料区域。
项目、意向及具体事项均可追加沟通记录。
顶部“回收站”可以恢复记录。回收项目或意向时，其关联内容随之隐藏。
编辑时如提示另一人已修改，请刷新后核对，避免覆盖对方的工作。

Codex 接入
已配套 codex-skill 技能、脚本和专用对话说明。
本机安装入口为“安装Codex接入.cmd”，输入后端地址，并用自己的看板账号连接。
专用聊天可使用 $modus-board，先按说明补充缺失信息，再提交到看板。
凭证保存在自己的技能目录 connection.json，分享接入包时排除此文件。
接口与脚本说明位于 codex-skill/references/接口与脚本.txt。

保存与退出
数据保存在程序目录下 data/modus.sqlite3，文件保存在 data/files。
退出浏览器不会清空数据。关闭启动窗口或按 Ctrl+C 可停止服务。
备份时先停止服务，再复制整个 data 目录。恢复时停止服务，替换整个 data 目录。
请同时保留数据库和 files 文件目录。

测试
双击 run-tests.cmd 运行后端自动化测试。测试使用临时数据库，不修改你的真实数据。
可选浏览器测试见 tests/browser_smoke.py，需要 playwright 及 Microsoft Edge。
安装测试依赖：py -3 -m pip install playwright
运行方式：python tests/browser_smoke.py --output 测试截图目录

2026-11-20 三阶段意向更新
现在有七个页面，新增成功项目、失败项目。
沟通意向按线索发现、沟通阶段、最终方案及报价已提交分列展示。
新增意向后可上传帖子图片和原文件。追加沟通时填写实际结束时间，分别保存原文与整理后的需求；记录可编辑，历史修订仍可查。
没有约定时，沟通阶段默认结束后24小时，方案报价已提交阶段默认提交/最新跟进结束后48小时。约定时间优先，同一意向只维护一条当前自动跟进待办。按中国标准时间和自然小时计算。
进入第三阶段前，请上传方案书和报价书，注明版本，编辑意向时选择两份最终文件并填写实际提交时间。
第三阶段明确失败时点“归档失败”，填写原因。成功达成合作后点“转入开发项目”，进入项目开发管理。
项目开发目录全部完成后仍可以等待尾款。在项目详情展开后点“登记尾款”，填写实际到账时间及备注。开发完成且全部尾款到账才进入成功项目。
尾款登记可清空纠错。明确恢复开发或撤销尾款到账登记会从成功列表移出；修改待办完成状态不会改变项目开发状态。
旧意向保留原内容，未推断其实际沟通阶段、发生时间和付款状态，资料可以逐项补齐。
给合伙人AI的说明已同步更新，接入凭证无需重新设置。

完整自动化验证
后端：py -3 -m unittest discover -s tests -v
全部：py -3 tests/run_all.py --browser --output 选定的测试报告目录
浏览器测试需 playwright Python包及已安装的 Microsoft Edge。app 本身仍只用 Python 标准库。
可运行目录内“运行完整测试.cmd”。测试仅用临时数据库和测试账号，不改 data 中的实际记录。

意向卡片停留颜色
自添加或上次有效改动起，不足3天为白底，满3天为灰底，满6天为黑底，按72/144自然小时计算。文字会按背景自动调整对比度。
真实编辑、沟通、文件更新、调整或完成跟进后恢复白底重新计时。查看、悬停、刷新不计入。
卡片显示距上次更新多少天，变黑不等于失败，不会自动归档。
历史修改时间未记录的旧卡片采用升级时刻作为计时起点，卡片有相应说明。
旧三阶段的原始信息和已有任务记录已保留。新八阶段的完成状态需要按实际成果确认，不会沿用旧待办自动推断的结果。

Codex 自动更新接入（2026-11-20）
点击顶部“Codex接入”，查看当前接入版本、最新技能与说明和客户端状态。
先设置一次DuckDNS固定发现名称及管理Token。Token只存后端，不回显，不分发给客户端。客户端通常直接连接已知地址，失效时才查询固定名称。
首次在本人账号中生成专用接入包，交给Codex专用会话，按包内说明自动执行bootstrap.py --workspace 专用工作目录。接入包有效期7天，绑定本人账号，不要公开。
首次安装UserPromptSubmit等Hook后，需由使用者在Codex的/hooks界面审阅并信任。普通规则更新不改变Hook命令，无需反复发包。若Codex未显示Hook，需要重开客户端后确认，不能把尚未信任的Hook说成已启用。
以后每条新消息只检查一次版本，不设定时任务。同一消息重复工具调用复用检查结果，没有更新返回304不下载正文，有更新只下载变化文件。
更新后的规则由当前会话读取并确认后才允许写入。版本过期、断网或校验失败时保留账号和完整本地版本，可先整理信息，暂停写入并提示原因。
开发端维护要求见开发端维护规范.md和本目录AGENTS.md。个人连接和首次激活包不属于公共发布文件。

回收站升级（2026-11-21）：删除内容默认保留30天，可恢复；到期由运行中的后端每小时检查并自动清理。历史回收记录从升级时起算。回收站新增到期时间、彻底删除和清空，先预览实际关联范围，再输入“永久删除”确认。正常成功/失败项目和工作归档不自动清理。后台按批次清理关联内容及不再使用的附件，文件占用时持久排队重试。数据库空闲页复用，独立备份不参与清理。
